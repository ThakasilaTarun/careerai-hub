# SYNOPSIS: CAMPUS PLACEMENT MANAGEMENT SYSTEM

### 1. PROJECT TITLE
CAREERAI HUB (Placement Control Center)

### 2. PROBLEM STATEMENT
Manual management of campus placements often leads to data redundancy, missed interview dates, and poor communication between the placement cell and students.

### 3. PROPOSED SYSTEM
An automated web-based solution that allows:
- **Centralized Data:** Storing all student and company info in a relational MySQL database.
- **Transparency:** Students can see their interview status in real-time.
- **Efficiency:** Admins can schedule and track hundreds of interviews through a single dashboard.

### 4. TOOLS & TECHNOLOGIES
- **Frontend:** HTML5, CSS3, JavaScript
- **Backend:** PHP 8.x
- **Database:** MySQL
- **Server:** Apache (XAMPP)
- **IDE:** Visual Studio Code / Notepad++

### 5. SYSTEM REQUIREMENTS
- **Hardware:** 4GB RAM, Intel i3 or above.
- **Software:** Windows/Linux/Mac, XAMPP/WAMP Server, Modern Web Browser.

### 6. CONCLUSION
The Campus Placement System effectively bridges the gap between students and recruiters by providing an organized, database-backed platform for career management.
